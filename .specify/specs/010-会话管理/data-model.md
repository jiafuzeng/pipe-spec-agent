# Data Model: 会话管理

会话、提问和运行事件仍在现有业务库。本模型只描述历史列表和继续聊天要读到的字段，不新增记忆类型。

## 会话

一段连续问答。

| 字段 | 规则 |
| --- | --- |
| `id` | 会话标识。一段对话一个标识。 |
| `created_at` | 创建时刻。没有提问时不作为最近活动时间。 |

没有用户提问的会话不进入历史列表。

## 历史会话条目

左侧列表中的一条，由一个会话导出。

| 字段 | 规则 |
| --- | --- |
| `session_id` | 等于 `会话.id`。 |
| `last_message` | 该段最近一次用户提问，必有。页面只显示开头一行。 |
| `last_activity_at` | 该次提问的时刻。列表按它从新到旧。相同文字的条目靠它区分。 |

校验：

- 两条属于不同会话的条目不得带有对方的提问。
- 该段又有新的用户提问时，`last_message` 和 `last_activity_at` 改为这一次，并重新排序。

## 聊天记录

打开一段会话时看到的内容。只属于该 `session_id`。

| 字段 | 规则 |
| --- | --- |
| 顺序 | 按发生顺序，从早到晚。打开时包含该段全部提问，不截断为最近 30 条。 |
| 提问 | 来自该段已保存的用户提问。 |
| 回答 | 来自这些提问对应的运行事件，包含已完成的回答。 |
| 归属 | 不得混入其他 `session_id` 的提问或回答。 |

状态：

1. 空白新对话。左侧还没有这一条。
2. 已有至少一次提问。出现在左侧，可被打开。
3. 正在等待回答。不能切换到其他会话。
4. 打开失败。说明暂时打不开，主区域不改成另一段的记录。

## 上次打开

| 字段 | 规则 |
| --- | --- |
| `session_id` | 本机浏览器记下的上次查看会话。只保存标识，不保存聊天正文。 |
| 缺失 | 标识不在历史列表中时，进入空白新对话，其余条目仍列出。 |

## 关系

- 一个会话有零到多条按时间排列的提问，以及这些提问产生的回答。
- 一条历史会话条目对应一个已有提问的会话。
- 上次打开最多指向一个会话。它不是第二条聊天记录。

## 明确不保存的内容

- 不把聊天正文复制到浏览器存储。
- 不在本模型里保存跨会话的工程参数或规程说法。
- 不保存会话别名、删除标记或搜索索引。
