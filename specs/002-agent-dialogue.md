# 002 Agent 规划、追问与会话状态

状态：Draft  
范围：意图识别、任务规划、澄清、参数记忆、工具执行和失败恢复。

## 目标

让 Agent 能规划技术规程问答和计算任务，同时保持执行路径可控、可审计。LLM 选择已定义的任务类型并组织语言；缺项判断、调用许可、计算与结论校验由确定性逻辑负责。

## 功能需求

### AG-01 任务分类与规划

支持条文问答、方法比较、检测方案分析、参数收集、规程计算、绘图和复合任务。规划结果是允许节点组成的有序步骤列表，至少可表达检索、澄清、工具调用、校验和回复。禁止自由生成可执行代码或未注册工具。

### AG-02 参数缺项先追问

根据计算类型关联的参数 Schema 检查必填项、单位、枚举、互斥/条件字段。缺失或含糊时输出结构化清单，逐项解释作用和规程出处；参数不完整时不得调用计算工具，也不得展示预测值。

### AG-03 场景信息充分性

检测方案规划前，将已知条件、影响判断的缺失条件和每项条件的用途分开展示。若缺失条件影响方法适用性、安全或现场操作，先追问；若 Spec 规定可基于明确假设继续，须展示假设并让用户确认。假设规则必须来自已核验规程依据。

### AG-04 会话内参数记忆

用户确认的参数保存在当前会话并与管段 ID 关联。每项包含值、单位、来源消息、确认状态和时间。再次计算同一管段时可复用已确认值；不得重复询问有效值。若目标管段改变、值冲突或单位/适用范围不明，先要求澄清。

### AG-05 可审计计划与工具日志

展示可验证的步骤状态（待执行、运行中、成功、失败、跳过）、输入摘要、工具名、调用 ID、耗时和结果摘要。不得将隐藏思维链作为日志；日志表达任务步骤和执行事实。

### AG-06 失败和恢复

工具超时/临时失败时保留会话状态和用户已确认数据，说明失败步骤并允许重试。参数错误、无依据和权限错误不自动重试。重试次数有上限且由服务端策略控制。失败不能产生成功样式或沿用其他输入的旧结果。

## 验收场景

### AG-01-A 复合规划

**Given** 用户要求解释 RI 公式并画 K 变化曲线，必要参数未给全。  
**When** Agent 解析请求。  
**Then** 规划包含检索公式/分档、收集参数、计算多个点、绘图、结果校验和引用回答；缺参时执行在追问节点暂停。

### AG-02-A 空输入智能问数

**Given** 用户只说“帮我算一下这条管道的修复指数 RI”。  
**When** 参数校验运行。  
**Then** 返回所有经核验 Schema 定义的必填参数及其作用/出处；MCP 计算工具调用数为零。

### AG-03-A 同管段复用参数

**Given** 用户在当前会话确认某管段的管径、管龄等值，并完成一次计算。  
**When** 用户要求在同管段只改变一个参数重算。  
**Then** 其他已确认且仍适用的值被复用，仅询问缺失/冲突项；日志显示复用来源。

### AG-04-A 管段切换隔离

**Given** 会话已有管段 A 参数。  
**When** 用户明确开始计算管段 B。  
**Then** 管段 A 参数不被静默套用；逐项收集 B 的缺项或由用户显式确认复用。

### AG-05-A 工具超时后安全恢复

**Given** 绘图 MCP 调用超时而计算成功。  
**When** Agent 生成响应。  
**Then** 可以展示已验证的数值及其依据，明确图表未生成并提供重试；不得伪称图表成功，也不丢失计算输入。

### AG-06-A 证据不足停止

**Given** 规划中的某步骤无法检索到规程证据。  
**When** Agent 到达答案校验。  
**Then** 仅对证据充分的子问题作答，其余部分按统一拒答或追问处理，不臆测补全。

## 未决项

- 各类检测方案题中的“必要缺失条件”清单和可继续条件。
- 参数跨轮有效期、管段识别字段和用户撤回/修改参数的交互。
- 流式输出时先显示计划还是先完成证据检索。
