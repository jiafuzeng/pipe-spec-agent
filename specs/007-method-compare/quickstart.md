# Quickstart: 检测方法对比与检测方案

在仓库根目录：

```sh
.venv/bin/python -m unittest tests.test_answers tests.test_dialogue -v
```

手工看一题时先按 README 启动 API 与前端，在规程问答中输入：

1. `CCTV、QV、声纳三种检测方式的官方术语定义分别是什么？各自的适用条件有何差异？`
2. `某 DN800 混凝土污水管，埋深约 4.5 m，管内水位约 60%，积泥较厚，位于城市次干道，现场不具备停水降水条件。请给出检测方案、实施顺序、安全措施和选择依据。`

有已审核索引时，第一题应按方法分段并给出选择结论。第二题应列出缺失项；只有检索原文写了水位或管径界限时，才出现「因此不能采用」。索引为空时两题都是固定拒答。
