# 03 计算规则规格

状态：Draft  
详细工具验收：见 [003 计算、MCP 与曲线](003-calculation-mcp.md)。  
需求来源：`01-requirements.md` R3/R4，以及第 7 至 9 题验收场景。

## 1. 计算职责

修复指数 RI、养护指数 MI、缺陷分值查询、分项 S/Smax/F 和等级判定均由 MCP 计算工具完成。Agent 负责识别意图、收集参数、检索来源、呈现工具结果；不心算、不自行查表、不修改工具返回值。

成功结果必须在同次工具调用中携带公式、参数取值及出处、各中间量、最终指标、等级和规程处置建议。计算失败或引用不匹配时，丢弃所有未核实的数值输出。

## 2. 规则数据模型

每条规则须包含：规则 ID、指标/分值类型、规则版本、发布状态、原文公式或表格行列映射、输入参数定义/单位/范围/边界、适用条件、分值/等级/处置建议、条款或表号、印刷页码、PDF 页序、PDF SHA-256、审核人与人工复核算例。

未经审核发布的规则不可被计算 MCP 使用。规则变更产生新版本，不覆盖旧计算记录。

**双人审核流程（T03）** 以 [008 计算规则双人审核](008-rule-dual-review.md) 为准：worksheet → A/B 对照 PDF → `validate_rules` → `pipe_assessment_mcp/rules/published/`。夹具包不得进入 published。

## 3. 槽位生成与计算流程

1. 根据 `calculation_type` 读取已发布的输入 Schema。
2. 将用户参数规范化为标准字段和值；保存原始表述、单位、来源轮次和确认状态。
3. 对照同一规程版本检查必填、单位、范围、组合条件和歧义。
4. 缺失或冲突时返回缺项/澄清清单，不调用计算工具、不输出指数或等级。
5. 完整时调用 MCP；将结果字段与工具返回值绑定后生成答案。
6. 在响应中列公式、输入表、计算过程、结论和条款引用。

MI 与 RI 各自定义槽位，不因共享字段而混淆规则。详细协议及边界见 `003-calculation-mcp.md`。

## 4. 第 7 题 RI–K 曲线

- 必须从式 8.3.4、表 8.3.4-1、表 8.3.5 读取公式、K 分档及等级结论。
- K=0、3、6、10 是用户要求的自变量点。每点均以同一规则版本调用 RI 工具。
- “固定其余参数”不能默认为任意数值；先复用已确认的同会话参数，否则结构化追问。参数齐全后才批量计算和绘图。
- **基准样例（已冻结，供演示与 `agentEval`）**：当用户未给出其余参数时，系统**不得静默填入**；用户确认或续问给出后，采用 `F=6`、`E=6`、`T=0`（与 `01`/`V09` 及 §7.1 一致）。该组数值仅在用户确认后进入计算；不得在首轮缺参时当作默认值写入会话。
- 图表点值与计算 MCP 返回逐项一致，并显示其余固定参数、K 和 RI 坐标值。

## 5. 第 8 题智能问数

用户未提供任何管段信息时，系统由**已发布或夹具已批准**的 RI Schema 自动列出必填槽位、作用、单位、条款/表号及当前状态。  
槽位按「用户可提供 / 工具可推导」分组，**不得把仅应由 MCP 推导的中间量（S、Smax、F）写成唯一必填用户项**：

| 用户可提供（满足其一即可闭合） | 工具推导 |
|---|---|
| 缺陷记录（类型/等级/间距）**或** 已确认的 F | S、Smax、F |
| K 或可唯一映射的道路/地区描述 | — |
| D（mm）**或** 已确认的 E | E（由表 8.3.4-2） |
| 土质表列**或** 已确认的 T | T（由表 8.3.4-3） |

当前轮不得输出 RI、RI 等级或工具计算结果。`agent_cases` 的 `AG-T08` 用 `missing_parameter_groups` 表达上述「或」关系，不以硬编码 `["F","K","E","T"]` 为唯一清单。

## 6. 第 9 题输入映射

按 `01-requirements.md` 已有的分步标准实施：

1. 先用缺陷分值 MCP 核对两处重度错口和题给单处分值 5；不一致则停止并报告表 8.2.3 的表值。
2. 间距 1.2 m 按需求基线的分组和系数规则处理；不得触发 1 m 内叠加规则。
3. D=1200 mm、K=6 按需求基线给定的表项映射，并在结果中展示核验依据。
4. “流砂”不是表 8.3.4-3 的列名。第（1）问先展示原表土质列并询问用户指定列；指定前不得计算 RI。对不依赖 T 的中间量是否单独计算，须严格按已发布子计算 Schema 和 `01-requirements.md` 阻断规则处理，不输出 RI 或等级。
5. 第（2）问中用户明确要求 T=0、6、8、10，视为对每个计算点的参数确认；工具逐点返回结果，绘图数据与结果一致。
6. 管龄 35 年和管材不得被额外转换成式 8.3.4 中未定义的系数；管龄仅按对应条款用于周期相关说明。

## 7. 参考算例（机器可核对）

下列算例供 `agentEval` 与 MCP 回归使用。`status` 标明是否已双人审核。

### 7.0 规则发布与夹具策略（编码前冻结）

| 环境 | 规则来源 | 可否产出 RI/MI 数值 |
|---|---|---|
| 生产 / 现场演示默认 | 仅 `status=approved` 且双人审核、含 `reference_cases` 的发布包 | 是；否则 `RULE_NOT_PUBLISHED` |
| CI / `agentEval`（`precondition.fixture_rules=true`） | `RULE_FIXTURE=1` 时加载 `agentEval/fixtures/rules/` 最小 RI 包（`status` 视为 approved **仅限该进程**） | 仅评测进程；不得写入演示知识库发布态 |
| 开发对照（无发布包） | 仓库不存放草稿 `kb/`；`rulebook()` 返回空 | 否；`AG-L0-04` / `AG-T-MI-01` 走 `RULE_NOT_PUBLISHED` |

约定：

1. **T03 完成前**：生产计算开关默认关闭；演示可走检索与导入，不算正式 RI/MI。
2. **夹具包**复现 §7.1 草稿式与四点 RI，供 `AG-L0-03`、`AG-T07`、`AG-T08` 契约红/绿灯；夹具变绿 ≠ 规程已审核。
3. **题 9 领域算例**（§7.2）在完整分组/系数发布前保持 `blocked_until=T03_domain`，禁止用夹具加权器强行对齐。
4. 报告必须写明 `rule_mode=fixture|published` 与 `rule_version`。

### 7.1 题 7：固定 F/E/T，扫 K（草稿公式）

对应夹具包 `agentEval/fixtures/rules/RI.min.json`（及历史草稿公式）式：

`RI = 0.7×F + 0.1×K + 0.05×E + 0.15×T`

固定 `F=6`、`E=6`、`T=0`，夹具 `rule_version` 为 `CJJ181-2012-fixture-ri-7.1`：

| K | RI | 等级（按草稿分档） |
|---|---|---|
| 0 | 4.5 | Ⅲ |
| 3 | 4.8 | Ⅲ |
| 6 | 5.1 | Ⅲ |
| 10 | 5.5 | Ⅲ |

`agent_cases` 中 `AG-T07` 次轮 `expect.results` 必须与本表一致。公式若经原文复核修改，先改本表与 `reference_cases`，再改评测期望。

### 7.2 题 9：缺陷推导目标值（待领域层落地）

在完整分组/系数/式 8.3.4 审核通过前，下列为目标验收值（来自 `01-requirements.md`），不是当前简化加权器的输出：

| 步骤 | 期望 |
|---|---|
| 两处重度错口 | 表 8.2.3 各 5 分；间距 1.2 m → n2，α=1.1；不触发 1 m 内叠加 |
| 中间量 | S=5.5，Smax=5，F=5.5；K=6，E=6 |
| 流砂 | 第（1）问先澄清土质列；确认前无 RI |
| T=0/6/8/10 | RI=4.75 / 5.65 / 5.95 / 6.25；均为 Ⅲ 级 |

`AG-T09` 在领域计算未发布前标记为 `blocked_until=T03_domain`，不得用简化加权强行变绿。

### 7.3 验收门槛

- 公式、分档边界、舍入、等级表和处置文本由人工对照原 PDF 审核。
- RI 与 MI 均有工具级参考样例和边界样例；题 9 覆盖土质列追问和 T 直接指定两条分支。
- 计算日志包含输入快照、规则版本、`result_id`、条款引用和调用 ID，可从记录复算。
- 缺参、单位不明、土质无法映射、规则未发布、工具超时均不能产出指数/等级。
