# 04 接口与参数槽位规格

状态：Draft  
本文定义 Agent/API/MCP 的逻辑契约。具体字段范围必须以人工核验的 CJJ 181—2012 公式和表格为准；“待核验”字段不得作为已发布规则运行。

## 1. 聊天与执行 API

### `POST /api/v1/sessions`

创建会话，返回 `session_id`、`created_at`、会话状态。

### `POST /api/v1/sessions/{session_id}/turns`

请求包含 `message` 和可选 `subject_id`。响应以 SSE 事件输出：

- `plan_step`：步骤 ID、类型、状态、可读标签；
- `clarification_required`：槽位清单及原因；
- `evidence`：条款引用卡片；
- `tool_call`：MCP 名称、调用 ID、状态、输入/输出摘要、耗时；
- `answer`：最终文本、引用 ID、结果/图表 ID；
- `error`：稳定错误码、可否重试、恢复提示。

API 不输出模型隐藏思维链。输入原文与参数确认事件应分开存储，以支持审计和用户修订。

## 2. RI/MI 槽位清单

任务基线明确 RI 由 F、K、E、T 等参数参与式 8.3.4，且需要 S、Smax 等中间量；完整字段和公式仍必须核对原文及规则章节，避免把中间变量误当用户输入。

| 类别 | 槽位 | 用户提供/工具推导 | 当前要求 |
|---|---|---|---|
| 管段识别 | 管段/会话关联 ID | 会话生成或用户指定 | 用于隔离同会话参数，不代表规程计算参数 |
| 管径 | D、单位 mm | 用户提供或已确认会话参数 | 按核验后的表 8.3.4-2 映射 E；范围与临界值待复核 |
| 地区重要性 | K 或道路/重要性描述 | 用户明确给 K；如文字映射需经确认 | 表 8.3.4-1 的真实分档及边界待核验 |
| 土质 | 原文表列类别或 T | 用户明确选择原表类别，或明确给 T | 表 8.3.4-3；不得将“流砂”擅自映射为某列 |
| 缺陷记录 | 类型、等级、位置/方向等原文要求字段 | 用户提供；工具查表 | 缺陷分值关联表 8.2.3，字段集合待对照原表冻结 |
| 缺陷空间关系 | 各缺陷间纵向距离 | 用户提供或报告录入 | 按 8.1.3/8.1.4 等已核验规则分组与合并 |
| S/Smax/F 等中间量 | 由规则定义 | 工具推导 | 不要求用户重复填写中间变量；含义、公式和依赖字段待核验 |
| 管龄/管材 | 年、材质 | 用户提供 | 按现有需求基线，管龄仅用于周期说明；不得擅自作为 RI 系数 |
| MI 专属参数 | 由 MI Schema 定义 | 用户提供或工具推导 | 必须单独核验公式、槽位及处置映射，不复用 RI Schema |

### 字段冻结准则

- 每个槽位包含 `name`、`label_zh`、`type`、`unit`、`required_when`、`enum/range`、`description`、`evidence_refs`、`source_status`。
- 用户文字输入只能在唯一映射时转成枚举/系数；映射不唯一时返回表列候选项让用户确认。
- 用户显式提供题目要求的 T 值视为确认值；计算批次中的每个点分别记录 T。
- 同一会话确认值可重用，需显示其关联管段与来源轮次；切换管段不能自动复用。
- 题 8 的“全部必填项”必须从已发布 Schema 生成，不能静态硬编码未经公式核验的字段列表。

## 3. MCP 接口

### `search_clauses`

入参：`query`、可选 `filters`、`top_k`。返回已审核条款证据及源版本。

### `get_calculation_schema`

入参：`calculation_type` (`RI|MI|defect_score`)、`rule_version`。返回字段 Schema、作用说明、来源和发布状态。

### `lookup_defect_score`

入参：经核验字段要求的缺陷属性。成功返回唯一表项、分值、出处；不唯一则返回 `needs_clarification` 和候选条件。

### `calculate_index`

入参：指标类型、规则版本、标准化参数对象和幂等键。成功响应包含公式、参数追踪、中间结果、最终值、等级/建议、证据和结果 hash；失败响应不含数值结果。

### `plot_curve`

入参：同一批计算的结果 ID、自变量及数据点、轴名/单位、固定参数摘要。成功响应包含图表资源、坐标数据和结果关联 ID。工具只能绘制输入数据，不可估算缺失点。

## 4. 错误码

| 错误码 | 含义 | Agent 行为 |
|---|---|---|
| `MISSING_PARAMETERS` | 必填参数缺失 | 结构化追问；不调用计算器 |
| `AMBIGUOUS_MAPPING` | 用户表述无法唯一映射到表项 | 展示已核验候选项并澄清 |
| `INVALID_PARAMETER` | 类型、单位或范围不合法 | 说明问题字段和合法格式；不重试 |
| `RULE_NOT_PUBLISHED` | 规则尚未审核发布 | 停止计算并提示无法核验 |
| `EVIDENCE_NOT_FOUND` | 没有支持结论的规程证据 | 使用章程固定拒答 |
| `TOOL_TIMEOUT` | MCP 超时 | 按配置有限重试；展示失败与恢复入口 |
| `TOOL_UNAVAILABLE` | 工具服务不可用 | 保留输入与计划；不展示旧结果 |
