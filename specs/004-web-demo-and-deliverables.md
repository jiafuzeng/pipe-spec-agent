# 004 Web 演示与项目交付

状态：Draft  
范围：Web 交互、规划日志、MCP 记录、图表展示、现场演示和书面交付。

## 目标

交付可在现场运行的 Web Agent。评审者能看到 Agent 如何规划、何时追问、检索了哪些条款、调用了哪些 MCP 工具、计算结果如何形成，以及图表如何对应结果。界面不暴露私有思维链，只呈现可验证的执行事件。

## 功能需求

### WEB-01 对话与补参

支持提问、连续追问和会话恢复。参数缺失时显示结构化清单，包含名称、当前值/待补充、单位、作用、出处和输入控件。用户提交后可确认或修改。

### WEB-02 规划与工具时间线

展示每个计划步骤、状态、工具名、调用 ID、开始/结束时间、耗时、成功/失败、输入/输出摘要和重试次数。计算和绘图结果须与日志调用 ID 关联。

### WEB-03 引用面板

答案中的条款号可点击，展开条款标题、证据片段、页码和来源版本。若检索无依据，显示统一拒答，不显示空洞的“引用”装饰。

### WEB-04 图表

曲线题以真实计算点绘图，显示横纵轴、单位、图例、各点数值、固定参数和规则版本。图表可下载为 PNG/SVG，数值可下载为 CSV。工具失败时显示失败状态，不显示旧图表冒充当前结果。

### WEB-05 演示题库

界面提供九道测试题快捷入口。快捷入口只填入用户问题，不绕过 Agent 流程。所有题仍需调用检索/参数校验/工具和引用流程。

### WEB-06 本地运行和交付材料

提供 Docker Compose、环境变量样例、数据库迁移/规程数据初始化命令、健康检查和停止方式。交付测试答卷、自查说明、现场演示脚本与实际运行截图。

### WEB-07 知识文档导入

管理员可上传原始 PDF/Markdown，并可将现有 DocMind `document.json` / `document.md` 作为清洗附件与原文件明确关联。PDF 无清洗附件时由后端调用 DocMind；提供 JSON 时复用 DocMind layout。导入记录显示原文件名、SHA-256、版次、大小、页数、解析来源、索引版本和审核状态。

### WEB-08 切片与 embedding 配置

导入前可选结构优先或固定句子切片、chunk size、overlap，以及后端注册表中的 embedding profile。用户可预览最多 10 个 chunk 的正文、页码、章节、条款、内容类型和长度。预览与实际导入必须使用同一参数快照。embedding 凭证不发送到浏览器；profile 不可用时禁用提交并给出原因。

### WEB-09 导入任务、审核和索引版本

文档解析、切片、embedding、Chroma 写入使用异步任务。页面可恢复查看进度、错误、重试和 chunk；写入全部成功后任务才完成。新文档默认待审核，人工批准后才参与 RAG。切片配置、embedding 模型/版本变化时创建新的 index version，不覆盖已发布版本。

## 界面验收场景

### WEB-01-A 追问可见

**Given** 用户请求 RI 计算且存在缺项。  
**When** Agent暂停等待补参。  
**Then** 页面显示全部缺项和作用/出处，执行时间线显示追问步骤和计算步骤未执行。

### WEB-02-A 工具链可见

**Given** 用户完成参数补充并触发计算。  
**When** MCP 调用开始并结束。  
**Then** 页面显示真实调用名称、状态、耗时、请求/响应摘要以及相关证据；不显示虚构步骤。

### WEB-03-A 引用可展开

**traces_to:** WEB-03  

**Given** 回答含条款号。  
**When** 用户点击引用。  
**Then** 展开条款标题、证据片段、页码和来源版本；无依据时显示统一拒答，不显示空洞引用装饰。

### WEB-04-A 曲线与数据一致

**traces_to:** WEB-04  

**Given** 计算工具返回多个自变量结果。  
**When** 图表渲染完成。  
**Then** 图上点值与工具返回数据表一致，轴名、单位、固定参数和来源可见；图片经 `/api/v1/artifacts/{resource_id}` 获取。

### WEB-05-A 现场重启复现

**traces_to:** WEB-06  

**Given** 新机器已安装 Docker。  
**When** 按 README 提供的命令启动服务并导入核验数据。  
**Then** 健康检查通过（含分量状态），九题演示入口可用，日志与图表均可生成。

### WEB-06-A 答卷证据完整

**traces_to:** WEB-06  

**Given** 九题验收均在同一候选发布版本实际运行。  
**When** 生成测试答卷和截图。  
**Then** 每题标注条款；第 6/7/8/9 题保留规定的追问、日志、工具记录和图表；截图与版本号/会话关联。

### WEB-06-B 自查说明

**traces_to:** WEB-06  

**Given** 应用完成候选发布。  
**When** 用户查看自查文档。  
**Then** 文档列出能力边界、已知缺陷、MCP 超时/失败处理、智能问数判定边界和后续计划，不宣称未验证能力。

### WEB-07-A 导入前预览

**Given** 管理员上传 CJJ 原文和对应 DocMind JSON，并选择切片与 embedding profile。  
**When** 点击预览。  
**Then** 页面展示结构化 chunk 及来源页码/layout 信息，明确预览不写向量库；参数非法或模型不可用时阻止确认导入。

### WEB-08-A 任务重启后可见

**Given** 一个导入任务正在解析或向量化。  
**When** 用户刷新页面或服务重启后重新打开任务列表。  
**Then** 页面从持久化任务记录恢复当前状态，不重复提交同一个文件和配置组合。

### WEB-09-A 审核后才可问答

**Given** 文档完成索引但处于 `pending_review`。  
**When** 文档管理员核对 PDF 并批准。  
**Then** 审核人/时间写入审计记录；批准前检索不返回该文档，批准后可按文档版本过滤检索。

## 交付验收清单

- [ ] Web 应用可按步骤本地运行。
- [ ] 可查看规划步骤、条款证据和 MCP 调用记录。
- [ ] 参数缺失时可暂停、补充、恢复并复用同会话已确认数据。
- [ ] RI 曲线由计算返回数据绘制，可下载图和数据。
- [ ] 九题逐题完成，有实际运行记录和条款出处。
- [ ] 测试答卷和自查说明与候选版本一致。
- [ ] 知识库可导入原文/DocMind 产物，预览切片，选择 embedding，并保留原文元数据。
- [ ] 新导入内容默认待审核；审核前不会进入问答检索。
- [ ] 答辩材料能解释 RAG、Agent 状态图、参数校验、MCP、异常策略和计算追溯。
