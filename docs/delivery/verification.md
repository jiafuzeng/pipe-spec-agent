# 现场演示准备情况

当前九题预检记录在同目录的 nine-questions-preflight.json。每题使用独立会话，记录题面、会话和回合标识、实际检索和工具事件。运行使用本地应用 ASGI 入口和同进程计算工具，关闭模型辅助规划，使用本地知识库和正式规则目录。此记录对应尚未发布知识的配置。

| 检查项 | 本次结果 |
| --- | --- |
| 条款检索 | 本地有一份待审核 Markdown 索引、109 个切片，已审核索引数为零。第 1–6 题返回固定拒答 |
| 计算门禁 | 正式规则目录为空。第 7–9 题返回 RULE_NOT_PUBLISHED。第 7 题同时记录公式检索 |
| 计算流程验收 | agentEval 使用独立夹具复现第 7 题四点曲线，以及第 8 题零计算调用的参数追问 |
| 现场验收 | 需从原始 PDF 导入、核对切片出处并人工批准。RI/MI 和缺陷分值的待审材料在 pipe_assessment_mcp/rules/worksheets。题 9 的双缺陷分组、S/Smax/F 推导、管径映射和土质追问已有代码及单项回归，仍需使用同一已审核版本的 RI 和缺陷查分包验收 |

## 复现步骤

1. 按根目录 README 分别启动前端、API 和 MCP。在导入页选择 docs 中的标准 PDF，预览切片并创建索引。在已入库文件下对照原文、核验版次和页码后，由审核人批准版本。
2. 打开规程问答，依次选择快捷题目并发送。第 5 题检查分项检索和引用。第 6 题检查管径、水位冲突和追问，同一管段补参后检查上下文。
3. 完成正式规则人工双审、算例复算及发布后运行第 7、8 题。先保留缺参时的工具日志，再补齐已确认的参数。检查四个结果引用、曲线点值和下载文件。
4. 在连接实际服务的环境执行下列命令保存当次九题的原始事件，在浏览器保存与该版本对应的证据、追问和曲线截图。每次使用新的输出文件名以保留预检记录。

```sh
.venv/bin/python -m agentEval.demo --api http://127.0.0.1:8000 --output docs/delivery/nine-questions-live.json
```
